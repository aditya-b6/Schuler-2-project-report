\chapter{Introduction}
\label{Chapter1}

Autonomous driving systems rely on accurate environmental perception to understand their surroundings and make safe driving decisions. For miniature autonomous vehicles, reliable real-time estimation of position, orientation, and velocity is essential for trajectory planning, collision avoidance, and closed-loop control. Achieving this using a single overhead fisheye camera presents several technical challenges, including severe wide-angle lens distortion, perspective distortion, segmentation uncertainty, and measurement noise, all of which can reduce localization accuracy.

This project addresses these challenges by developing an infrastructure-based, vision-based vehicle localization framework. The proposed system integrates threaded image acquisition, fisheye camera calibration, ArUco-based homography coordinate transformation, YOLOv8 instance segmentation for vehicle sub-part detection, and an Extended Kalman Filter (EKF) for robust vehicle state estimation. By combining perception-based pose estimation with probabilistic filtering, the framework provides stable real-time estimation of vehicle position, orientation, and velocity suitable for miniature autonomous vehicle research and structured indoor test environments.


\section{Motivation}

Autonomous driving research has highlighted the importance of robust perception systems through standardized benchmark datasets and evaluation frameworks for vehicle detection and localization in real-world scenarios \cite{geiger2012kitti}. These developments have significantly advanced computer vision techniques for intelligent transportation systems.

For miniature autonomous vehicle platforms, deploying expensive sensor suites such as LiDAR or multiple synchronized cameras is often impractical because of hardware, computational, and budget constraints. Infrastructure-based perception using a stationary overhead camera provides a practical alternative by offering a global view of the driving environment while reducing onboard sensing requirements.%
\sidenote{An overhead camera provides a global field of view of the entire test track, reducing self-occlusions and enabling continuous observation of all vehicles within the monitored area.}

Despite these advantages, accurate vehicle localization from overhead imagery remains challenging due to wide-angle fisheye lens distortion, perspective distortion, segmentation uncertainty, and measurement noise. Integrating deep-learning vision models with recursive state estimation is therefore essential for transforming noisy image observations into smooth and reliable real-world vehicle trajectories.

\section{Objectives and Contributions}

The primary objective of this project is to develop a reliable infrastructure-based vehicle localization framework for miniature autonomous vehicles using an overhead fisheye camera, enabling accurate vehicle detection and pose estimation while improving runtime performance and localization stability.

The main contributions of this project are summarized as follows:

\begin{itemize}
	\item Development of a vision-based vehicle detection and localization pipeline using YOLOv8 instance segmentation for vehicle sub-part detection and homography-based coordinate transformation.
	
	\item Integration and optimization of an Extended Kalman Filter (EKF) using a CTRV kinematic model for robust vehicle state estimation and smoother pose tracking.
	
	\item Implementation of runtime enhancements, including threaded camera streaming, fisheye image undistortion, and jitter suppression for stable localization.
	
	\item Experimental evaluation of the proposed framework through localization performance, latency, vehicle velocity, and residual analysis using real-time visualization tools.
\end{itemize}
